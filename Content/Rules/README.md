# 外部游戏模式

编辑 `game-modes.json` 即可调整模式，不需要 Unity 或重新构建。
在 MainMenu 点击 **Reload database / game modes** 加载修改；在卡组编辑场景会自动检查文件变化。战斗期间锁定配置，结束后再加载。

## 测试入口

1. 两个客户端都从 MainMenu 开始，选择 **测试模式（允许重复卡）**。
2. 各自点击 **Load mode example deck (replace current)**：载入 1 张 PD01-001 契约和 49 张 PD01-004。按钮会替换当前模式卡组。
3. 一方 Host，另一方 Join。双方必须使用相同模式及 Content 配置。
4. 开局牌堆为 49 张背面卡，约 0.8 秒后自动抽 5 张，剩余 44 张。进入 Draw 阶段抽 1 张，剩余 43 张。
5. 第一个回合按配置经过 TurnStart → Draw → Main → End；第二回合起恢复完整阶段。

标准模式与测试模式分别保留当前运行期间的编辑结果，切换不会把测试卡组带入标准模式。卡组未实现跨游戏重启存档。
Host 根据本地规则重新校验每位玩家提交的卡组，洗牌、发牌和抽牌均由 Host 执行。客户端只收到自己的手牌和双方剩余牌数，不收到对手手牌或牌库顺序。

## 配置字段（version 为 1）

`modes` 数组中每项定义一个模式；复制一个模式并改为唯一 `id` 即可增加菜单选项。

| 字段 | 含义 |
| --- | --- |
| id / name | 唯一标识 / 菜单显示名称；首次启动默认选数组第一项 |
| deckSize | 开战所需主卡组数量，含契约、不含附带玩家卡；2–200 |
| maxCopies | 同 ID 上限；1–deckSize |
| cardLimits | 可选的逐卡上限，例如 `{"PD01-014": 0}` 表示该模式禁用；只能比 maxCopies 更严格 |
| requireSameFaction | 是否限制为契约同国家或泛用国家 |
| genericFaction | 泛用国家的 Lua faction 值，默认 `不明` |
| openingHand | 初始手牌数；0–deckSize-1 |
| drawPerTurn | 每次进入抽卡阶段时抽的张数；0–20 |
| firstTurnSkip | 仅整场第一个回合跳过的阶段，可填 Rebuild、TimeReset、Combat；空数组不跳过 |
| exampleDeck | 可选示例卡组，格式为卡片 ID 到数量；ID 必须存在于外部 Lua 数据库 |

`banlist.json` 是所有模式共用的逐卡限制（0 为禁用），与模式限制取更严格值。`{}` 表示无额外限制。
每组必须有且仅有一张等级 0 契约；必须先选契约才能添加其他卡。契约引用的两张玩家卡自动附带、不进入牌库。这些是当前引擎固定结构，不属于可调整字段。

错误 JSON、未知字段、越界值以及会使已有卡组不合法的修改都会拒绝加载，保留之前的数据。若要收紧规则，先在编辑器移除超限卡，再重新加载。

当前战斗仍是行动测试：不结算召唤消耗、决策卡效果、Lua 效果、未来视或牌库耗尽后的洗弃牌堆/伤害。决策卡可以抽入手牌，但不能当普通时魔召唤。JSON 只能配置已实现的规则，不能凭字段新增机制。
