# 玩家卡随契约移动

## 当前规则

- `AttachPlayers` 将发动契约控制玩家的两张玩家卡一起放在契约下方，保持当前正反面，随契约移动。
- 玩家附着期间不能被直接攻击。攻击目标不会移动到承载契约所在圆阵；必须先处理契约，使玩家返回原玩家区，再按正常规则攻击玩家。
- 承载契约离场、被破坏、效果失效或被超频覆盖时，解除随行并返回原玩家区。恢复效果或重新登场不会自动恢复旧随行关系，需要重新发动。
- 返回时原玩家区已有时魔，玩家仍放在时魔下方，不挤走该时魔，也不占用额外时魔位置。该时魔及原有防御圆阵继续保护玩家。
- 附着／解除本身不翻面、不抽牌。契约离场的翻面、抽牌仍只由契约离场规则执行一次。
- 附着不是超频。玩家卡不会作为超频素材被破坏，也不会随时魔进入弃牌区或契约区；当前正面玩家卡仍可按其正常发动条件操作。

## Lua 与内核

```lua
effects = {
    oncePerTurn = true,
    activationCosts = { { kind = "Time", amount = 1 } },
    canActivate = function(ctx)
        return ctx.clock == "black"
    end,
    onActivate = function(ctx)
        return {
            { op = "Modify", stat = "range", amount = 1, duration = "turn" },
            { op = "AttachPlayers" }
        }
    end
}
```

已用于 HZ01-020-R / HZ01-020-SP。攻击距离增益到回合结束；附着关系持续到来源失效或离场。`range` 按地图连接的最短路径计算，仅影响攻击，不增加契约移动距离。实际战斗核与本地菜单使用相同距离。

独立指令类为 `AttachPlayersEffect`，关系维护于 `MatchPlayerCards`，绑定来源 GUID 与场上实例代次。快照的玩家卡含 `AttachedTo` 和当前 `NodeId`，时魔含 `AttackRange`。主机在攻击宣言与后续结算重新检查玩家是否仍可被攻击。协议版本20。

## 交互与显示

时魔和玩家卡共处圆阵时，普通单击卡片或圆阵会打开已有的2D卡片选择窗，选择时魔或正面玩家卡后打开其操作菜单。背面玩家卡不可操作。已有的选目标、拖拽操作优先处理，不被普通浏览弹窗截断。

所有存在玩家卡的圆阵均为它们预留底层空间，时魔／超频堆叠放在其上方。拖动承载契约时玩家卡一起预览移动；松手后以主机确认的位置为准。返回原玩家区后仍使用同样的底层摆放规则。

已补内核回归：随行移动、无效返回、覆盖返回、破坏返回且原区有时魔、重入不恢复旧关系、附着期间免直接攻击、攻击诱发中新建立附着后取消待处理玩家攻击，以及实际两种印刷版本的费用／距离／持续期。另新增 Unity 几何测试，实际 Unity 双端点击和拖拽仍需 Play Mode 验证。
